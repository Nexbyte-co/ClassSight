# Week 4 journal

## What I worked on

This week I replaced the placeholder face recognition code with a real pipeline that uses a pretrained model. I did not train anything myself. The system finds the faces in a photo, turns each face into a list of numbers, and compares those numbers with the stored ones for the enrolled students.

Pipeline: the photo is checked for faces, each face is aligned and converted into a 512-number fingerprint, and that fingerprint is compared with every enrolled student. A match is accepted only when the score is at least 0.5 and clearly better than the second-best student. Both values are rough starting guesses, not tuned yet.

Enrollment: each enrollment photo must contain exactly one clear face. The fingerprints from a student's photos are averaged and saved in the database. I kept the photos out of storage at this stage, so only the averaged fingerprint is kept.

Tests: I wrote tests for the matching rules using made-up fingerprints, and tests for enrollment with the model replaced by a fake. All six matching tests passed.

## Problems I ran into and how I solved them

**The full test suite would not run.** The tests need a running Postgres database, and Docker was not running on my laptop. I ran the tests that do not need the database and left the full suite for when Docker is working.

**Frontend packages were missing.** Two packages were listed in the project but were not installed, so the app would not start. Running `npm install` fixed it.

**The frontend needs a backend to pass the login check.** Without a backend, the route guard sent me back to the login page. For local testing I set a dummy token in the browser's local storage, which lets me open the pages. This is only for development. It is not a real login.

**Tightly cropped faces are not found.** A 112 by 112 pixel photo of a face, cropped right to the edges, gave zero detections. The detector needs some background around the face. This matters for ID-card style photos. My plan is to add padding around the image before detection, and I will check this when I test on real photos.

**A security warning from npm.** `npm install` reported one high-severity vulnerability. I noticed it but have not looked into it yet.
