# Week 8 journal

## What I worked on

Added NFC attendance. A student's ID card can now be linked to them by an admin, and a teacher can mark attendance by tapping the card on a phone. I also added an admin area for managing other administrators and for changing an admin's own password, and made the admin Settings page more usable.

Card linking: the admin opens a student's page and presses "Link card", then taps the card on the phone or types its serial number. Each card can belong to only one student.
Card attendance: the teacher opens the NFC tab on the attendance page or the dashboard and taps each student's card. The student is marked present on the page, and nothing is saved until the teacher presses Save.
Admin settings: a new Administrators tab lists current admins and adds new ones. A My account tab lets an admin change their own password and sign out other devices.

## Problems I ran into and how I solved them

Web NFC did not work on my laptop's address. Chrome only allows it on HTTPS or localhost, and the phone could reach the laptop only over plain HTTP. I solved this with Tailscale: the laptop and phone joined a private network, and `tailscale serve` gave the laptop a real HTTPS address that the phone can open.

Vite refused the new address. The dev server only accepts host names it knows, so I allowed the Tailscale domain in the Vite config.

Linking showed on the phone but not on the laptop. The admin page had loaded its list before the card was linked. Reloading the page fixed it, so the admin list now updates after a link or unlink.

Phone pairing was more complicated than it needed to be. I built a way for a teacher on a laptop to show a code and have a phone read the cards for it. It worked in tests, but it added a public page and a second way to take attendance, so I removed it and kept the simpler version where the phone reads its own cards.

Taps on the dashboard could not be saved directly. The attendance page is the only place that saves a whole class, so saving a single tap would have left everyone else blank. I made the dashboard collect the taps and pass them to the attendance page, where the teacher reviews them and saves.

Photos did not load on the phone. The server gives the browser photo links that point at my laptop's local storage, which the phone cannot reach. I decided to leave this until the app is deployed on AWS, where photos come from S3 over HTTPS.
