The Problem: In the active session banner, Course / Subject unexpectedly wrapped to a second line. Root Cause: The container used grid-template-columns: 1fr 1.2fr 1.5fr;, but had 5 child elements (3 column divs + 2 divider divs). The vertical dividers consumed grid column tracks 2 and 4, which forced column 5 onto row 2. Creative Solution: Replaced CSS Grid with Flexbox: display: flex; align-items: stretch; justify- content: space-between;. Added dedicated width: 1px; background: var(--cs-border); flex-shrink: 0; dividers. Standardized all 3 columns with uniform .col-value rules (22px, font-weight: 700, line-height: 1.25) so all labels, values, and subtexts aligned on exact horizontal baselines. 2. Ephemeral Theme State Across Client-Side Navigation The Problem: Turning on dark mode in Dashboard reset back to light mode as soon as the teacher clicked "Reports" or navigated using the browser back button. Root Cause: isDarkMode was isolated in individual component useState(false) hooks. When routes unmounted, state was discarded. Creative Solution: Created a centralized [ThemeContext.jsx] (ﬁle:///home/parv/ClassSight/frontend/src/context/ThemeContext.jsx) with custom hook useTheme(). Wrapped <BrowserRouter> inside <ThemeProvider> in [App.jsx] (ﬁle:///home/parv/ClassSight/frontend/src/App.jsx). Synchronized state with localStorage.getItem("classsight_theme") and dynamically toggled .dark-mode on document.documentElement and document.body. Dark mode now persists seamlessly across all routes and full browser reloads. 3. The "Stuck Start Date" Calendar Range Flaw The Problem: In the custom report calendar, clicking any date after day 1 would set the end date, but users could never choose a start date greater than 1. Root Cause: The naive handler logic checked if (day < rangeStartDay) setRangeStartDay(day); else setRangeEndDay(day);. Because rangeStartDay was initialized to 1, any click on days 2..30 always triggered the else branch. Creative Solution: Designed a 2-click state machine: 1. Click 1: Captures the start date, sets isPickingEnd = true, and highlights a single cell (.range-single). 2. Click 2: Captures the end date.
